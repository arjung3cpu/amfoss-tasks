## A problem I'd genuinely like to solve

One problem I've noticed is how difficult it can be for students to keep
track of everything.

Assignments, notes, deadlines, study plans and projects often end up
being spread across different apps, chats and files. It becomes easy to
forget something or spend more time organising everything than actually
doing the work.

I'd like to build something simple that can bring these things together
without becoming another complicated application.

This is one of the ideas behind my Task 10 project, B.Tech Survival Hub.
I wanted it to be something a student could actually use for keeping
track of tasks, focus sessions and daily progress.

I think this matters because a small amount of organisation can make
student life a lot less stressful.

A lot of what I've learned has come from working on my own projects.

I've worked on Arduino projects, including a motion detection project,
experimented with Raspberry Pi, built websites and practised programming
through different problems.

I also completed an ACM bridge course at Amritapuri and a Java

A lot of my learning has looked like this:

`write code -> run it -> get an error -> figure out what it means -> try again`

Doing this over and over has made me much more comfortable with

I've learned that I don't need to know everything before starting

### Task 10 - B.Tech Survival Hub

A personal productivity dashboard made using HTML, CSS and JavaScript.

It includes task management, daily progress, a focus timer, a percentage
calculator, random project ideas and motivational quotes.

I tried to make it feel like something I could actually use as a student
instead of making it only for the task.

### Task 11 - TimeFlow Wallpaper Sync

A Python application that reads a text file and displays its contents as
a desktop wallpaper.

It includes a live clock, automatic updates when the text file changes,
long-text handling and handling for missing and empty files.

This was one of my favourite tasks because I could actually see the
program working directly on my desktop.
