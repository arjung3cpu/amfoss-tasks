# Task 04 – Codeforces Problem Solving

## Overview

I solved the five assigned Codeforces problems using Python and tested each solution before submitting it to Codeforces.

## Problems Solved

### 1. The 67th OEIS Problem

**Problem:** 2218D

I constructed the required sequence using consecutive prime numbers so that every adjacent pair has a different GCD.

**Concepts used:**
- Prime numbers
- GCD
- Constructive algorithms

### 2. Digit String

I used a split-point / prefix-counting approach to determine the minimum number of deletions required.

**Concepts used:**
- Strings
- Prefix counting
- Greedy reasoning

### 3. Another Puzzle from Papyrus

I considered the possible costs with and without reordering and selected the minimum valid cost.

**Concepts used:**
- Sorting
- Greedy algorithms
- Array processing

### 4. Good times Good times

I used the property that multiplying `x` by `10^d + 1`, where `d` is the number of digits in `x`, creates a number containing repeated copies of `x`.

**Concepts used:**
- Mathematics
- Number construction
- Digit manipulation

### 5. Duck Surplus

I processed the piles greedily and maintained the minimum possible final largest pile.

**Concepts used:**
- Greedy algorithms
- Arrays
- Iterative processing
